# Experiments

For each experiment, record:

1. Observed failure and baseline.
2. Proposed mechanism and falsifiable prediction.
3. Dataset or cases, controls, metrics, and stopping rule.
4. Exact configuration and reproducible command.
5. Results, limitations, and artifacts.
6. Human decision to promote, revise, or reject the mechanism.

For context or compaction changes, measure task success, total tokens and cost, latency, cache
continuity, recovery failures, and information loss—not only the next request's size.
