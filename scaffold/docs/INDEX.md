# Project documentation index

Use this page as the routing layer. Read only the section relevant to the current task.

- `product/README.md`: user problem, desired behavior, scope, and acceptance criteria.
- `research/README.md`: sources, evidence, open questions, and rejected hypotheses.
- `design/README.md`: architecture, interfaces, constraints, and consequential decisions.
- `decisions/README.md`: short durable decision records and their status.
- `experiments/README.md`: falsifiable hypotheses, methods, results, and promotion decisions.
- `runbook/README.md`: commands, prerequisites, side effects, failures, and recovery.
- `project-status.md`: current objective, completed work, blockers, verification, and exact next step.

Add links here when a new durable document is created. Do not turn this index into a second copy of
the documents it routes to.
