# Coding norms

This directory contains proposed runtime-neutral coding norms. Read
`docs/specs/norm-library.md` before authoring or promoting a norm.

The current files are deliberately small draft scaffolds. Their presence demonstrates hierarchy,
selection, and relations; it does not make their content canonical policy.

Author one independently applicable rule per norm. Keep the rule and rationale together, but place
long examples in separate `on_demand` norms linked with `example_of`. Directory hierarchy is for
humans and indexing; it does not imply that every ancestor, sibling, or related node is ingested.
